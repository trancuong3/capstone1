ANDROID DELIVERY TRACKER

Android / APK readiness

Đường đi từ Android source đến file APK có thể cài đặt, chạy và sử dụng được trên điện thoại thật.

Trạng thái audit gần nhất: Android source đã được merge vào main; các kiểm tra compile, lint và JVM tests từng thành công. Những GitHub Actions run đã rà soát không tạo APK artifact vì bước assemble bị bỏ qua. Chưa có bằng chứng cài đặt trên điện thoại thật. Hãy cập nhật checklist khi có bằng chứng mới.

Quy tắc nghiệm thu

Chỉ đánh dấu “Hoàn thành” khi có bằng chứng: APK file + SHA-256 + xác minh chữ ký; cài đặt thành công; khởi chạy; đăng nhập/session; API; camera/microphone/audio; và thử nghiệm trên thiết bị Android thật. Emulator không thay thế real-device verification.

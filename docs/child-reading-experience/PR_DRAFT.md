# Complete the child reading flow with immutable assessment and revision-bound images

The reading flow could lose first-pass evidence during retry or page revisits, consume incorrect attempts for technical uncertainty and show images from a different OCR revision. This change preserves the original page/revision/word snapshot, persists retry outcomes before advancement and reports self-correction separately from the original score. Capture, recognition and timed playback use cancellation/identity guards; selected voice metadata and speed are preserved. Admin image replacement remains revision-bound and reviewable, while the child viewer chooses an overlay or readable OCR fallback.

Regression coverage includes lost-response replay, three-attempt limits, completed-session protection, duplicate finalization, concurrent retry/progress writes on disposable PostgreSQL, native browser capture, offline recovery, page transitions, magnification and input safety. New metadata writes are bounded without rewriting historical rows. No application migration or runtime dependency was added; frontend/backend contracts must be deployed together.

The later geometry correction normalizes light text on dark source images and requires content-bound evidence before image overlays. Legacy/untrusted boxes use the existing image-reference/OCR-text fallback without changing historical revisions.

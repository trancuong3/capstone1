- **Automated Secrets Regex Scan (`d5eee4dc..HEAD` + untracked RC code + all `docs/research/viread-optimal-zero-cost-architecture/**`):** **0 hits** across OpenAI (`sk-`), Google (`AIza`), JWT (`eyJhbGciOi`), Supabase (`sb_secret_`), Groq (`gsk_`), PEM private keys, and local user `.env` paths.
- **Hardened RC Controls Verified:** All high/medium baseline code gaps targeted in the RC sprint (`429` sliding-window rate limits, `12 MB` chunked `match-page` upload cap + bounded queries, `Active == 1` DB enforcement on `/voice/*` & `/support/feedback`, `0` duplicate OpenAPI routes across `235` paths, Next.js CSP & security headers, `auth/callback` origin allowlist, `X-ViRead-Cron-Token` constant-time auth, proxyless owner-scoped signed URLs, soft-delete `409 BOOK_SOFT_DELETED` fencing, tenant-safe OCR SHA-256 cache, and non-root `ocr_worker` Docker hardening) are **implemented in code and verified by tests**.
- **Remaining Open Security & Privacy Risks (4):**
  1. **[MEDIUM] `role_cache.py` 60-Second Deactivation Lag:** `require_active_profile_id` delegates to `role_cache.py` (`_ROLE_TTL_SECONDS = 60.0`), so deactivating an account (`profiles.active = 0`) leaves `/voice/*` and `/support/feedback` (plus `get_cached_profile_role` routes) accepting that user's requests for up to `60s` (`role_cache`) / `45s` (`auth_token_cache`).
  2. **[MEDIUM] In-Process Memory State & Quick Tunnel Surface:** `rate_limiter.py` and `role_cache.py` are process-local (`1` Render worker assumption); `Start-ViReadTunnels.ps1` Quick Tunnel (`*.trycloudflare.com`) still lacks Cloudflare Access Service Token enforcement until upgraded to a Named Tunnel.
  3. **[MEDIUM] Browser WASM / Option 5 CSP Prerequisite:** `frontend/next.config.ts` intentionally omits `'wasm-unsafe-eval'` and `COOP`/`COEP` headers today — safe for current RC, but must be explicitly scoped before enabling Option 5 Browser WASM `sherpa-onnx`.
  4. **[LOW / BLOCKED ON FREE] Supabase Free Leaked Password Protection:** Disabled on Supabase Free (requires Supabase Pro `$25/mo`).

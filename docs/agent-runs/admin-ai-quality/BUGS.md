# ViRead Admin AI Quality — Bugs Found & Fixed

| ID | Severity | Area | Root Cause | Fix & Verification |
| --- | --- | --- | --- | --- |
| BUG-01 | P0 | Verification Gate / Auto-Verify Bypass | `AdminOcrService.verify` and `admin-book-ai-batch-review.tsx` allowed `AI_AUTO_VERIFIED` and raw-OCR auto-verify fallbacks without explicit Admin confirmation. | Disabled `AI_AUTO_VERIFIED` server-side (`409 AI_AUTO_VERIFY_DISABLED`), required `workflow_id`, refactored batch review UI to queue durable workflow & draft only. Verified in `test_book_rights_and_verification_gate.py` & E2E 1–2. |
| BUG-02 | P0 | Auto-Publish Bypass | `BookContentQualityService.auto_publish_if_eligible` and `admin_ai_workflow_worker._try_auto_publish` could auto-publish books without explicit Admin book approval. | Disabled `auto_publish_if_eligible` (returns `False`, zero DB mutations), removed calls from worker & `verify`, preserved legacy v2 `AUTO_APPROVAL` published records via `legacy_assessment_hash`. |
| BUG-03 | P0 | Worker Runtime Crash | `admin_ai_workflow_worker.py` threw `KeyError: 'book_id'` when invoking auto-publish post-stage. | Removed `_try_auto_publish` calls from worker stages; persisted chunk completeness & `image_safety_status` in `SafetyMetadata`. |
| BUG-04 | P0 | Image Safety Unchecked | Child Safety only evaluated text (no vision model), yet nothing separated Text Safety from Image Safety or required manual Admin image review before verify. | Added `SourceImageSha256`, `ImageSafetyStatus`, `ImageSafetyReviewedAt/By/ImageSha256/Reason`, `POST .../image-safety-decision`, UI separation, and strict verify gate (`IMAGE_SAFETY_UNASSESSED`, `IMAGE_SAFETY_FLAGGED_UNSAFE`, `IMAGE_SAFETY_STALE`). |
| BUG-05 | P0 | Stale Safety After Draft Edit | `AdminOcrService.save_draft` updated revision text without invalidating matching `AdminAiWorkflow` safety results. | Added `_invalidate_workflows_for_draft_change` marking workflows `STALE` and archiving prior safety in `SafetyHistory`; `verify` rejects `CANDIDATE_HASH_MISMATCH`. |
| BUG-06 | P0 | Missing Rights Evidence Persistence | Rights review was only a boolean flag (`rights_confirmed`) hardcoded `false` in frontend with no evidence model, history, or page-verify enforcement. | Added additive migration `bookrightsevidences` + `bookrightsevidencehistory`, `GET/PUT /books/admin/quality/books/{book_id}/rights`, content fingerprint staleness, and enforcement on both page verify and book approval. |
| BUG-07 | P1 | Cloud Timeout Starving Ollama | Slow/hung cloud providers consumed the entire `total_timeout_seconds` budget, starving local Ollama fallback. | Added `_cloud_attempt_timeout` budget reservation in `orchestrator.py` and preserved `upstream_status_code` on Gemini/Groq/Ollama providers. Verified with unit tests + real local Ollama fallback test. |
| BUG-08 | P1 | Book Quality Ollama Escaping & Schema Fallback | `book_quality_ollama.py` double-escaped `\\n`/`\\t`, lacked `think: False`, `trust_env=False`, and 400/422 JSON-mode retry. | Fixed prompt newlines, added `think: False`, `trust_env=False`, `follow_redirects=False`, and 400/422 retry with `"format": "json"`. Verified against real local Ollama `qwen3-vl:4b-instruct-q4_K_M`. |
| BUG-09 | P1 | Baseline Test Crash (`NameError: uuid4`) | `backend/test_admin_ocr_child_safety.py:431` used `uuid4()` without importing `uuid4`. | Imported `uuid4` in M1. |
| BUG-10 | P1 | Multi-Chunk Proofreading Index Mismatch | `prompts.py` & `admin_ocr_local.py` emitted global `token.index` while `response_json_schema` and `validators.py` expected 0-based chunk-local indices. | Normalized emitted token indices to 0-based chunk-local indices in `prompts.py` and `admin_ocr_local.py`. |
| BUG-11 | P1 | Book Approval Idempotency Bug | `decide_book` compared `latest_metadata["rights_confirmed"]` against raw `payload.rights_confirmed` instead of `effective_rights_confirmed`, causing repeat `APPROVE` to re-commit. | Fixed idempotency comparison to use `effective_rights_confirmed`. Verified by `test_repeating_the_same_book_approval_is_idempotent`. |
| BUG-12 | P1 | Parent Report Internal Findings Leakage | `get_parent_report` shared serializer with Admin and could expose internal Admin scan `related_findings`. | Added `include_internal_findings=False` on Parent report serialization and verified Parent A/B 404 IDOR isolation. |
| BUG-13 | P1 | Structured Error Codes Hidden in Frontend | `frontend/lib/api/api-client.ts` only checked `typeof payload.detail === "string"`, falling back to generic error for `{code, message}` dict details from M3/M4 gates. | Extended `safeBackendMessage` to map allowlisted `detail.code` values to Vietnamese messages while never reflecting raw unallowlisted server messages. Verified in `api-client-error-codes.test.ts`. |
| BUG-14 | P2 | Visual Layout Clipping in OCR Review Card | Real Playwright desktop screenshot (`e2e3`) showed `xl:grid-cols-5` clipping `NOT_RECOMMENDED`/`CONFIRMED` and `sm:flex-row` squeezing the Image Safety note input inside the half-width right column. | Changed metric grid to `sm:grid-cols-2` with `min-w-0 break-words` and stacked the Image Safety note input vertically (`flex-col gap-3`). Visually re-verified via updated desktop screenshot. |
| BUG-15 | P2 | Legacy Unit Test Mock Compatibility | `test_admin_ocr_text_sync.py` passed sync `MagicMock` as `db.scalars`; `test_admin_ocr_local_api.py` missed `word_normalizer=normalize_word`; `run_ci_tests.py` needed opt-in real Ollama class allowlist. | Guarded `_invalidate_workflows_for_draft_change` with `inspect.isawaitable(pending)`, updated mock expectation in `test_admin_ocr_local_api.py`, and allowlisted `RealLocalOllamaFallbackTests` in `run_ci_tests.py`. |
